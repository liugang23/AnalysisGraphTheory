网络构建系统文档
? 概述

网络构建系统是金融网络分析工具箱的核心模块，负责从配对分析结果构建网络结构，包括网络矩阵初始化、统计指标计算和数据验证。

? 模块架构
主要模块组成
网络构建系统
├── network_construction_core.m    (模块1) 网络构建核心
├── network_statistics_calculator.m (模块3) 网络统计计算
└── validate_network_structure.m   (模块4) 网络结构验证

? 输入参数说明
1. 主函数调用参数
    [pair_network, network_stats, node_statistics, validation_report] = ...
        network_construction(pairwise_results, analysis_type, varargin)

参数	               类型	 必需	  默认值	 说明
pairwise_results	结构体	   是     -	     配对分析结果
analysis_type	    字符	    是	  -	      分析类型：'correlation' 或 'granger'
varargin	        单元格	   否	 -	     可选参数对

2. pairwise_results 结构体
    % 必需字段
    pairwise_results.pair_info = struct数组;  % 配对信息
    pairwise_results.corr_matrix = 矩阵;     % 相关矩阵（相关分析）
    pairwise_results.granger_results = 结构体; % Granger因果结果

    % 可选字段
    pairwise_results.var_names = 单元格;      % 变量名称
    pairwise_results.time_info = 结构体;      % 时间信息
    pairwise_results.config = 结构体;         % 配置信息

3. 可选参数（名称-值对）
    % 网络构建参数
    'correlation_threshold', 0.8          % 相关阈值
    'p_value_threshold', 0.05             % p值阈值
    'granger_f_stat', 3.0                 % Granger F统计量阈值
    'min_lag', 1                          % 最小滞后阶数
    'max_lag', 5                          % 最大滞后阶数

    % 输出控制参数
    'display_progress', true              % 显示进度
    'validation_level', 'standard'        % 验证级别
    'save_intermediate', false            % 保存中间结果
    'output_path', './output/'            % 输出路径

? 内部函数详细说明
1. network_construction_core.m
功能: 网络构建核心模块，初始化网络结构
输入:
    [pairwise_results, analysis_type, param_info]

处理流程:
    从pairwise_results提取节点信息
    创建节点索引映射
    初始化网络矩阵
    填充邻接矩阵
    计算边权重
    记录方向信息
    记录滞后信息
    记录显著性水平

输出字段详解:
    node_index_map: 容器Map，键为节点名，值为索引
    node_labels: 包含所有节点名称的单元格数组
    ret_nodes/obv_nodes: 分类节点列表
    adjacency: 稀疏布尔矩阵，表示连接关系
    weights: 权重值矩阵（相关强度或Granger F值）
    directions: 方向矩阵（1=正向，-1=负向）
    lags: 最佳滞后阶数矩阵
    significance: 显著性p值矩阵

2. network_statistics_calculator.m
功能: 计算网络拓扑统计指标
主要计算的统计量:
统计量	          公式/计算	                             意义
网络密度	    density=N(N?1)2E	?	               实际边数与最大可能边数之比
聚类系数        Ci=ki?(ki?1)2Ti                        节点邻居间的连接程度
平均路径长度    L=N(N?1)1∑i=jdij	?	                节点间平均最短距离
模块度          Q=2m1∑ij[Aij?2mki?kj]δ(ci?,cj)        社区结构强度
度中心性  	    CD(i)=N?1ki	?	                       节点直接连接数归一化
接近中心性	   CC(i)=∑j=i?dijN?1	?                 节点到其他节点的平均距离倒数
介数中心性	   CB(i)=∑s=i=tσstσst(i)	           节点在最短路径中的中介作用

3. validate_network_structure.m
功能: 网络结构验证和质量控制
验证级别:
    basic: 基本结构验证（必需）
    standard: 基本+数值合理性验证（推荐）
    strict: 完整验证，包括一致性检查

验证项目:
    1、必需字段检查
    2、维度一致性验证
    3、值域合理性检查
    4、对称性检查（无向图）
    5、自环检查
    6、NaN/Inf值检查
    7、与源数据一致性检查
    8、孤立节点检查

? 网络矩阵格式说明
1. 相关网络（无向）
    邻接矩阵: symmetric, binary (0/1)
    权重矩阵: symmetric, continuous [0,1]
    方向矩阵: all 1 (positive correlation)
2. Granger因果网络（有向）
    邻接矩阵: asymmetric, binary (0/1)
    权重矩阵: asymmetric, continuous (F-statistic)
    方向矩阵: causal direction (+1 for X->Y)
    滞后矩阵: best lag order

? 验证报告解读
验证结果等级
    通过: 所有必需检查通过，可安全使用网络
    警告: 通过必需检查，但存在潜在问题
    失败: 必需检查失败，网络不可用

常见警告及处理
   1、 自环检测: 检查是否允许自相关
   2、 不对称矩阵: 检查是否应为对称网络
   3、 值域异常: 检查权重是否在合理范围
   4、 孤立节点: 考虑是否保留或过滤
   5、 维度不匹配: 检查节点标签与矩阵维度
